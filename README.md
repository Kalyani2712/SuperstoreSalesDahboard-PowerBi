
# 📊 SuperStore Sales Dashboard – Data Analyst Internship Task

This repository contains a Power BI dashboard project created as part of the **Elevate Labs Data Analyst Internship (Task 8)** under the Ministry of MSME, Government of India.

---

## ✅ Objective

To design a **simple, clean, and interactive dashboard** that displays sales performance insights by:
- Product Category
- Region
- Segment
- Monthly trends

---

## 📁 Dataset

- `Superstore_Sales_Dataset.csv`
- Contains: `Order Date`, `Region`, `Category`, `Segment`, `Sales`, `Profit`, `Payment Mode`, `Ship Mode`

---

## 🛠 Tools Used

- Microsoft Power BI

---

## 📊 Dashboard Features

- **Slicers:** Region filter (Central, East, South, West)
- **Visuals:**
  - Line Charts (Monthly Sales & Profit)
  - Donut Charts (Region, Segment, Payment Mode)
  - Bar Charts (Category, Sub-category, Ship Mode)
  - Map (Sales by State)

---

## 📌 Key Insights

1. 🗺️ **West region** leads with **33%** of total sales.
2. 📱 **Phones** are the top-performing sub-category with **$0.20M** in sales.
3. 📈 **December** had the highest monthly sales and profit.
4. 🚚 **Standard Class** is the most used shipping mode (**$0.33M**).
5. 🛍️ **Consumers** account for **48%** of total sales.
6. 💳 **Cash on Delivery (COD)** is the most preferred payment method (43%).
